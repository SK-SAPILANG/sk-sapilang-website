SK SAPILANG WEBSITE CONTENT ADMIN — ONE-TIME SETUP

1. Create or open a Google Spreadsheet for the website content.
2. Open Extensions > Apps Script.
3. Delete the sample Apps Script code, then paste everything from CMS-Code.gs.
4. Run setupWebsiteCMS once and approve the requested permission.
5. In Apps Script, open Project Settings > Script Properties.
6. Add this property:
   CMS_ADMIN_PASSWORD = your private password
   Do not place this password inside any HTML file.
7. Deploy > New deployment > Web app.
   Execute as: Me
   Who has access: Anyone
8. Copy the deployed Web App URL.
9. In cms-config.js, paste that URL here:
   window.SK_CMS_ENDPOINT = "YOUR WEB APP URL";
10. Upload the updated website to GitHub.
11. Open content-admin.html, enter the same Web App URL and password, then edit the site.

IF YOU PREVIOUSLY DEPLOYED AN OLDER CMS VERSION
- Replace the old Apps Script code with the latest CMS-Code.gs.
- Run setupWebsiteCMS again once. This creates or updates WEBSITE_ITEMS for projects, programs, galleries, publications and scheduled evaluations without deleting existing changes.
- Select Deploy > Manage deployments > Edit.
- Choose New version, then click Deploy.
- Keep the same /exec Web App URL.
- The latest version enables the hidden response frame required by the Content Admin. If the admin shows a timeout, confirm that you deployed a New version after pasting the latest CMS-Code.gs.

HOW TO EDIT
- Choose a page.
- Click Open Page.
- Click visible text, a button, link, or image in the preview.
- Choose Words/Text, Link Address, Image Address, or Show/Hide.
- Enter the new content and click Save Change.
- Refresh the public page to see the saved update.

IMAGE NOTE
Use a public image URL. For Google Drive, make the image available to anyone with the link and use a direct-view URL. Do not use private files.

SCHEDULED ACTIVITY / EVALUATION
- Open feedback.html, select Admin and log in to the QMS Dashboard.
- Open the Manage Activities tab.
- Enter the activity name, date, venue and resource speaker, then click Add Scheduled Activity.
- You can also edit or delete scheduled activities from the same QMS tab.
- If the website CMS password differs from the QMS access code, enter it in the optional Website CMS Password field.
- The Feedback page will automatically show the saved activity as a choice and fill its details for evaluators.

VISITOR LOGBOOK
- The Visitor Logbook and Client / Service Feedback are combined in one form inside feedback.html.
- The form records the visitor's essential details, office or organization, position, purpose, service and optional service rating.
- Run setupWebsiteCMS again once to create or safely update the VISITOR_LOGBOOK columns.
- The visitor must accept the Data Privacy consent before the entry is recorded.

GAD AND INCLUSION DATA
- The Visitor Logbook, Activity Evaluation and Suggestions forms now include the same voluntary GAD and inclusion profile.
- Run setupWebsiteCMS again once to create the GAD_INCLUSION_DATA sheet.
- The sheet stores the form reference number, sex assigned at birth, optional gender identity/expression, optional pronouns, organization/office, position and selected sector classifications.
- Respondents may select Prefer not to say. Selecting Other or Self-describe opens a field where they can provide their own answer.
- Use the reference number to relate the demographic record to its QMS submission while limiting unnecessary duplication of names.
