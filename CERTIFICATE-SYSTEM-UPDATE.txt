SK SAPILANG QMS + DIGITAL/HARD COPY CERTIFICATE SYSTEM

Included in this package:
- Optional email address
- Digital / Hard Copy / Both certificate preference
- Digital certificate recommended for reduced paper use
- Hard copy available three (3) days after successful evaluation submission
- Activity-type evaluation, including non-speaker programs such as kaBOTEhan and school-supply distribution
- Automatic certificate generation and QR verification
- Different certificate presentation by activity/program category
- Admin certificate access and hard-copy tracking
- Blank certificate printing option

DEPLOYMENT
1. Upload/replace the website files in the GitHub Pages repository.
2. In Google Apps Script, replace Code.gs with the separate CMS-Code.gs provided with this package.
3. Save and run setupWebsiteCMS() once.
4. Authorize requested permissions if prompted.
5. Deploy the existing Web App as a new version.
6. Test one activity evaluation from submission through certificate viewing/verification.
